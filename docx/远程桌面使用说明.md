# 远程桌面使用说明（x11vnc）

在 Windows 上远程查看和操作这台 Linux 上**正在运行的 dwm 桌面**，两边看到的是同一个画面。

- 脚本：`bin/vnc.sh`
- 平时不运行，需要时手动开启
- 连接方式：Windows 直接连 `Linux的IP:5900`
- 只允许局域网地址（`192.168.*`、`10.*`）连接，公网来的连接会被拒绝

> **安全提醒：** 直接连接时，VNC 的画面和键盘输入都**不加密**。局域网里有人抓包，就能看到你输入的内容，包括锁屏密码。
> VNC 密码最多只有前 8 位有效。只在家里等可信的网络里使用，用完随手关掉。

---

## 1. 首次准备

### Linux 端（只需要做一次）

```sh
sudo pacman -S x11vnc              # 或在项目根目录执行 ./setup.sh deps
~/projs/dwm2/bin/vnc.sh passwd     # 设置 VNC 连接密码(按提示输入两次)
```

密码保存在 `~/.vnc/passwd`。

### Windows 端（只需要做一次）

安装 **TigerVNC Viewer**：到 <https://github.com/TigerVNC/tigervnc/releases> 下载 `vncviewer64-*.exe`，这是单个文件，不用安装，直接运行。

---

## 2. 连接步骤

**第一步：在 Linux 上开启远程桌面**（任选一种）

| 方法 | 操作 |
|---|---|
| rofi 菜单 | `Super + P` → `󰢹 open vnc` |
| 终端 | `~/projs/dwm2/bin/vnc.sh start` |
| 从 Windows 远程开启 | 在 PowerShell 执行 `ssh jiang@192.168.67.224 "~/projs/dwm2/bin/vnc.sh start"` |

开启后，右上角的通知会显示连接地址，比如 `已开启 (192.168.67.224:5900)`。

**第二步：在 Windows 上打开 TigerVNC Viewer，连接这个地址**

```
192.168.67.224:5900
```

输入第 1 节里设置的 VNC 密码，就能看到 dwm 桌面。

**断开与关闭：**
- 关掉 VNC Viewer，就断开了画面。x11vnc 会继续运行，可以随时重连。
- 不用的时候要关掉 x11vnc，有两种方式：
  - 在 Linux 上按 `Super + P` → `󰢹 close vnc`，或执行 `vnc.sh stop`
  - 在 Windows 上执行 `ssh jiang@192.168.67.224 "~/projs/dwm2/bin/vnc.sh stop"`

> Linux 的 IP 可能会变（比如换了 Wi-Fi）。在 Linux 上执行 `bin/vnc.sh status` 可以查看当前地址。

## 3. 使用注意

| 问题 | 说明 |
|---|---|
| **Win 键（Super）** | 窗口模式下，Win 键会被 Windows 自己截获。在 TigerVNC 里按 `F8` 打开菜单，选择 **Full screen** 进入全屏，Win 键就会传给 Linux，dwm 的快捷键就能正常使用。再按一次 `F8` 可以退出全屏 |
| **分辨率** | 画面是 Linux 的 2560×1440。TigerVNC 不能缩放画面，Windows 屏幕较小时会出现滚动条。需要缩放的话，改用 **RealVNC Viewer**（连接方式相同），在 View → Scaling 里选择自适应窗口 |
| **锁屏** | 10 分钟无操作会自动锁屏、关闭显示器。远程画面也会显示锁屏界面，直接输入 Linux 密码解锁即可 |
| **复制粘贴** | 文字剪贴板在两边互通，图片不支持 |
| **本机屏幕** | 远程操作时，Linux 电脑前的屏幕会同步显示操作过程，别人能看到 |
| **画面不刷新** | 断开后重连；还不行就在 Linux 上执行 `vnc.sh stop`，再执行 `vnc.sh start` |

## 4. 故障排查

| 现象 | 处理方法 |
|---|---|
| 通知提示「未设置密码」 | 在 Linux 终端执行 `bin/vnc.sh passwd` |
| 连接超时 | 先确认两台电脑在同一个局域网：在 Windows 上 `ping 192.168.67.224`。再确认 Linux 防火墙放行了 5900 端口 |
| 连接被拒绝 | x11vnc 没在运行：在 Linux 上执行 `bin/vnc.sh status` 查看 |
| 其他问题 | 查看日志：`~/.cache/x11vnc.log` |
