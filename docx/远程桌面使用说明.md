# 远程桌面使用说明（x11vnc）

在 Windows 上远程查看和操作这台 Linux 上**正在运行的 dwm 桌面**，两边看到的是同一个画面。

- 脚本：`bin/vnc.sh`
- 平时不运行，需要时手动开启
- x11vnc 只接受本机连接，Windows 必须通过 SSH 隧道连过来。VNC 本身不加密，走 SSH 隧道后，整个传输过程都是加密的

---

## 1. 首次准备

### Linux 端（只需要做一次）

```sh
sudo pacman -S x11vnc              # 或在项目根目录执行 ./setup.sh deps
~/projs/dwm2/bin/vnc.sh passwd     # 设置 VNC 连接密码(按提示输入两次)
```

密码保存在 `~/.vnc/passwd`。VNC 密码最多只有前 8 位有效。

### Windows 端（只需要做一次）

1. 安装 **TigerVNC Viewer**：到 <https://github.com/TigerVNC/tigervnc/releases> 下载 `vncviewer64-*.exe`，这是单个文件，不用安装，直接运行。
2. 确认有 ssh 命令：Windows 10/11 一般自带。在 PowerShell 里执行 `ssh -V`，有输出就说明可以用。

---

## 2. 连接步骤

**第一步：在 Windows 的 PowerShell 里建立隧道，并启动远程桌面**

```powershell
ssh -L 5900:localhost:5900 jiang@192.168.67.224 "~/projs/dwm2/bin/vnc.sh start; sleep infinity"
```

输入 Linux 的登录密码后，这个窗口**保持打开**，不要关。

这条命令做了两件事：
- 建立 SSH 隧道：Windows 的 5900 端口会被转发到 Linux。
- 在 Linux 上启动 x11vnc：不用走到 Linux 电脑前操作。

**第二步：打开 TigerVNC Viewer，连接**

```
localhost:5900
```

输入第 1 节里设置的 VNC 密码，就能看到 dwm 桌面。

**断开：**
- 关掉 VNC Viewer，就断开了画面。x11vnc 会继续运行，可以随时重连。
- 再关掉 PowerShell 窗口，隧道也就断开了。
- 想同时关闭 x11vnc，在 Linux 上按 `Super + P` → `󰢹 close vnc`，或者执行 `vnc.sh stop`。

> 如果 Linux 的 IP 变了，把命令里的 `192.168.67.224` 换成新的 IP。在 Linux 上执行 `ip -4 -br addr` 可以查看当前 IP。

---

## 3. 在 Linux 上开关

| 方法 | 命令 |
|---|---|
| rofi 菜单 | `Super + P` → `󰢹 open vnc` / `󰢹 close vnc` |
| 终端 | `bin/vnc.sh start` / `bin/vnc.sh stop` / `bin/vnc.sh status` |

开启和关闭时，右上角会弹出通知。

---

## 4. 使用注意

| 问题 | 说明 |
|---|---|
| **Win 键（Super）** | 窗口模式下 Win 键会被 Windows 自己截获。在 TigerVNC 里按 `F8` 打开菜单，选择 **Full screen** 进入全屏，Win 键就会传给 Linux，dwm 的快捷键就能正常使用了。再按一次 `F8` 可以退出全屏 |
| **分辨率** | 画面是 Linux 的 2560×1440。TigerVNC 不能缩放画面，Windows 屏幕较小时会出现滚动条。需要缩放的话，改用 **RealVNC Viewer**（连接方式相同），在 View → Scaling 里选择自适应窗口 |
| **锁屏** | 10 分钟无操作会自动锁屏、关闭显示器。远程画面也会显示锁屏界面，直接输入 Linux 密码解锁即可 |
| **复制粘贴** | 文字剪贴板在两边互通；图片不支持 |
| **本机屏幕** | 远程操作时，Linux 电脑前的屏幕也会同步显示操作过程，别人能看到 |
| **画面不刷新** | 断开后重连；还不行就在 Linux 上执行 `vnc.sh stop` 再 `vnc.sh start` |

---

## 5. 故障排查

| 现象 | 处理方法 |
|---|---|
| `ssh` 连不上 | 确认两台电脑在同一个局域网，并在 Linux 上执行 `systemctl status sshd` 检查 SSH 服务 |
| 通知提示「未设置密码」 | 在 Linux 终端执行 `bin/vnc.sh passwd` |
| VNC Viewer 提示连接被拒绝 | 隧道没建好或 x11vnc 没运行：检查 PowerShell 窗口是否还开着，再执行 `bin/vnc.sh status` |
| 其他问题 | 查看日志：`~/.cache/x11vnc.log` |
