# 远程桌面使用说明

在 Windows 上远程查看和操作这台 Linux 上**正在运行的 dwm 桌面**，两边看到的是同一个画面。

| 方案 | 说明 |
|---|---|
| **Sunshine + Moonlight**（主要） | 用显卡把画面实时编码成视频流，60 帧、流畅、默认全屏，声音也会一起传过去 |
| x11vnc + VNC Viewer（备用） | 不需要配对、装好就能用，但画面卡顿，只适合临时用一下 |

两种方案平时都不运行，需要时从 `Super + P` 菜单手动开启。

> 两种方案都只允许局域网连接，传输的内容没有经过额外加密，只在家里等可信的网络里使用。

---

## 零、Tailscale：固定 IP（推荐先做）

手机热点每次打开都可能换网段，局域网 IP 会变，每次都要在 Moonlight 里重新输入。**Tailscale** 会给每台设备分配一个**固定不变**的虚拟 IP（`100.x.x.x`）。两台电脑都装上并登录同一个账号后，不管连的是手机热点、家里 Wi-Fi 还是外面的网络，都用这个 IP 互相连接。

**Linux 端：**

```sh
sudo pacman -S tailscale                 # 或 ./setup.sh deps
sudo systemctl enable --now tailscaled   # 后台服务, 开机自启
sudo tailscale up                        # 终端会打印一个登录链接, 用浏览器打开并登录
tailscale ip -4                          # 查看本机固定的 Tailscale IP (100.x.x.x)
```

**Windows 端：** 到 <https://tailscale.com/download> 下载安装，用**同一个账号**登录。

**Moonlight 里改用 Tailscale IP：** 点右上角「+」，输入 Linux 的 Tailscale IP（`tailscale ip -4` 显示的那个），再删掉原来用局域网 IP 添加的主机。配对记录会保留，一般不需要重新输入 PIN。

装好后，`sunshine.sh start` 的通知和 `sunshine.sh status` 都会优先显示 Tailscale IP；网页控制台也可以用 `https://<Tailscale IP>:47990` 访问。

> **如果连不上：** 你开着 Clash 之类代理的 TUN 模式（虚拟网卡 `Meta`），它可能会拦截 Tailscale 的流量。可以在代理规则里把 `100.64.0.0/10` 设为直连，或者把 Tailscale 相关的进程和网段加进代理的排除列表。

## 一、Sunshine + Moonlight

- Linux 端：**Sunshine**，开关脚本 `bin/sunshine.sh`，配置文件 `config/sunshine.conf`
- Windows 端：**Moonlight**
- 编码：Intel 核显硬件编码（VAAPI）；BIOS 切到独显直连（没有核显）时，脚本自动改用 X11 抓屏 + NVIDIA 编码（NVENC）

### 1. 首次准备

**Linux 端安装（只需要做一次）：**

```sh
sudo pacman -S intel-media-driver libva-utils   # Intel 核显硬件编码驱动
yay -S sunshine-bin                             # Sunshine
```

安装后执行 `vainfo`，输出里出现 `VAProfileH264...: VAEntrypointEncSlice` 这样的行，就说明硬件编码可以用。

**Windows 端安装：** 到 <https://moonlight-stream.org> 下载安装 Moonlight。

### 2. 首次配对（只需要做一次）

1. **在 Linux 上开启 Sunshine**：`Super + P` → `󱒃 open sunshine`。
2. **打开 Sunshine 的网页控制台**，在 Linux 或 Windows 的浏览器里都可以：
   - Linux 上：`https://localhost:47990`
   - Windows 上：`https://192.168.67.224:47990`

   浏览器会提示证书不安全，这是正常的，点「继续访问」。第一次打开时，**设置一个用户名和密码**，这是网页控制台的登录账号。
3. **在 Windows 上打开 Moonlight**。它一般会自动发现这台 Linux 电脑；没有发现的话，点右上角的「+」，手动输入 `192.168.67.224`。
4. **点击这台电脑**，Moonlight 会显示一个 **4 位 PIN 码**。
5. **在网页控制台输入 PIN 码**：打开 **PIN** 页面，填入 PIN 码和一个设备名（比如 `windows`），点 Send。

配对完成后，以后连接都不用再输入 PIN 码。

### 3. 日常连接

1. 在 Linux 上开启 Sunshine：`Super + P` → `󱒃 open sunshine`。不在 Linux 电脑前时，也可以在 Windows 的 PowerShell 里远程开启：
   ```powershell
   ssh jiang@192.168.67.224 "~/projs/dwm2/bin/sunshine.sh start"
   ```
2. 在 Moonlight 里点击这台电脑，再点 **Desktop**，就会全屏显示 dwm 桌面。
3. 用完后按 `Ctrl + Alt + Shift + Q` 退出串流。
4. 不用时关掉 Sunshine：在 Linux 上 `Super + P` → `󱒃 close sunshine`，或者远程执行 `sunshine.sh stop`。

### 4. Moonlight 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl + Alt + Shift + Q` | 退出串流 |
| `Ctrl + Alt + Shift + X` | 全屏 / 窗口切换 |
| `Ctrl + Alt + Shift + Z` | 释放 / 重新捕获鼠标键盘（释放后可以操作 Windows） |
| `Ctrl + Alt + Shift + S` | 显示 / 隐藏性能统计（帧率、延迟、码率） |

**Win 键：** 在推荐设置下，全屏时 Win 键会传给 Linux。但 **Win + L**（锁屏）、**Win + G**（Xbox Game Bar）等组合键会被 Windows 系统抢先处理，传不过去。
这时用 **右 Alt** 代替 Win：Sunshine 已经配置了 `key_rightalt_to_key_win`，会把右 Alt 当作 Win 发送。例如：

| 按键 | 在 dwm 中等于 |
|---|---|
| `右 Alt + L` | `Super + L`：聚焦右边的窗口 |
| `右 Alt + G` | `Super + G`：切换全局窗口 |
| `右 Alt + 其他键` | `Super + 其他键` |

### 5. 推荐设置（Moonlight → 设置）

| 设置项 | 推荐值 | 说明 |
|---|---|---|
| 分辨率 | 1080p | 和 Windows 屏幕一致；Linux 的 2560×1440 画面会自动缩放 |
| 帧率 | 60 FPS | |
| 视频码率 | 40–50 Mbps | 太低（比如自动选的 7 Mbps）文字会糊；Wi-Fi 不稳定时调低 |
| 视频编解码器 | HEVC (H.265) | 同样码率下画质更好 |
| 优化鼠标以用于远程桌面而不是游戏 | 勾选 | 不勾选时鼠标会过快、飘 |
| 显示模式 | 全屏 | |
| 捕获系统键盘快捷键 | 仅全屏时 | 开启后，Win 键会传给 Linux，dwm 的快捷键才能用 |

### 6. 修改 Sunshine 配置

配置文件是 `config/sunshine.conf`，`~/.config/sunshine/sunshine.conf` 软链接到这里。在网页控制台里改的设置也会写回这个文件。改完要重启 Sunshine 才会生效：`sunshine.sh stop`，再执行 `sunshine.sh start`。

| 想改什么 | 改哪一项 |
|---|---|
| 换成 NVIDIA 显卡编码（画质更好，但更耗电） | `encoder = nvenc`，并删掉 `adapter_name` 这一行 |

### 7. 故障排查

| 现象 | 处理方法 |
|---|---|
| Moonlight 找不到电脑 | 先确认 Sunshine 在运行（`bin/sunshine.sh status`，会显示应添加的 IP）；再在 Moonlight 里手动添加这个 IP；还不行就检查防火墙是否放行 TCP 47984、47989、47990、48010 和 UDP 47998–48000 |
| 网页控制台登录或提交时报错（日志里有 `CSRF protection blocked`） | 必须用 `sunshine.sh start` 启动：它会把当前 IP 加进允许的来源。换网络后 IP 变了，要重启 Sunshine（先 `stop` 再 `start`） |
| 能连上但黑屏，或报编码错误 | 查看日志 `~/.config/sunshine/sunshine.log`；执行 `vainfo` 确认硬件编码可用；或者改用 `encoder = nvenc` |
| 画面正常，但鼠标键盘没反应 | Sunshine 需要 `/dev/uinput` 的权限，重启电脑一般就能解决 |
| 画面卡顿 | 在 Moonlight 里调低码率，按 `Ctrl + Alt + Shift + S` 查看统计：如果显示网络丢帧，就是 Wi-Fi 的问题 |
| 鼠标飘移、不跟手 | ① 在 Moonlight 里勾选「优化鼠标以用于远程桌面而不是游戏」；② 关闭 Moonlight 的垂直同步 |
| Linux 本机没有声音 | 串流时声音会转到 Windows 播放，退出串流后就会恢复 |

## 二、x11vnc（备用）

- 开关脚本 `bin/vnc.sh`；Windows 端用 TigerVNC Viewer，下载地址：<https://github.com/TigerVNC/tigervnc/releases>
- 画面会缩放到 1920×1080

**首次准备：**

```sh
sudo pacman -S x11vnc
~/projs/dwm2/bin/vnc.sh passwd     # 设置 VNC 密码(最多前 8 位有效)
```

**连接：**
1. 在 Linux 上按 `Super + P` → `󰢹 open vnc`，或者在 Windows 上执行 `ssh jiang@192.168.67.224 "~/projs/dwm2/bin/vnc.sh start"`。
2. 在 TigerVNC 的连接窗口点 **Options → Screen**，勾选 **Full-screen mode**。
3. 连接 `192.168.67.224:5900`，输入 VNC 密码。
4. 不用时关闭：按 `Super + P` → `󰢹 close vnc`。

如果 Windows 屏幕不是 1080p，用 `VNC_SCALE` 指定缩放比例，比如 `VNC_SCALE=1 bin/vnc.sh start` 表示不缩放。日志位置：`~/.cache/x11vnc.log`。

## 通用注意

| 问题 | 说明 |
|---|---|
| **锁屏** | 10 分钟无操作会自动锁屏，12 分钟关闭显示器（远程时可在 `Super + P` 里暂停自动锁屏）。远程画面也会显示锁屏界面，直接输入 Linux 密码解锁即可 |
| **本机屏幕** | 远程操作时，Linux 电脑前的屏幕会同步显示操作过程，别人能看到 |
| **IP 变化** | 换了 Wi-Fi 后 IP 可能会变。执行 `bin/sunshine.sh status` 或 `bin/vnc.sh status` 可以查看当前 IP |
