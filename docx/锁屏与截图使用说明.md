# 锁屏与截图使用说明

---

## 1. 锁屏（betterlockscreen）

锁屏脚本是 `bin/blurlock.sh`，底层用 betterlockscreen（基于 i3lock-color）。锁屏背景是当前壁纸调暗并模糊后的效果，屏幕中央显示时间和日期（中文星期），屏幕最底部是一排铺满整个宽度、随按键跳动的白色竖条。

### 什么时候会锁屏

| 情况 | 说明 |
|---|---|
| 按 `Super + Ctrl + L` | 立即锁屏 |
| 右键状态栏菜单图标 → ` 锁定` | 立即锁屏 |
| 9 分 30 秒没有操作 | 屏幕调暗提醒，这时动一下鼠标或键盘就恢复，不会锁屏 |
| 10 分钟没有操作 | 自动锁屏 |
| 12 分钟没有操作 | 关闭显示器 |
| 睡眠 / 休眠前 | 先锁好屏再睡眠，唤醒时不会先露出桌面 |
| 不想被自动锁屏（看视频、演示） | `Super + P` → pause auto lock，用完再 resume |

自动锁屏由 `xss-lock` 负责，调暗提醒是 `bin/dimscreen.sh`。这几个时间都在 `bin/dpms.sh` 里设置（`ALERT_SEC` / `CYCLE_SEC` / `OFF_SEC`）；改熄屏时间时，`config/betterlockscreenrc` 的 `lock_timeout` 也要一起改。

### 解锁

直接输入登录密码，然后按 `Enter`。

- 每按一个键，底部的竖条会随机跳起一段再迅速回落；"输入密码解锁"会变成圆点 `●●●`，个数就是已输入的位数，方便确认有没有多按或漏按。
- 密码错误时屏幕底部会亮起一条半透明的白色横带，并显示"密码错误"。
- 开着 Caps Lock 时，圆点下方会有提示。
- 按 `Esc` 或 `Ctrl + U` 可以清空已经输入的内容。**用按键唤醒屏幕后，先按一次 `Esc`**，否则唤醒用的那个键会被算进密码。

> **输对了密码还提示错误？** 系统默认 15 分钟内连续输错 3 次会把账户锁定 10 分钟，锁定期间输入正确的密码也会显示"密码错误"。等 10 分钟，或者切到文本终端（`Ctrl + Alt + F2`）登录后执行 `faillock --reset`。锁定规则在 `/etc/security/faillock.conf`（`deny`、`unlock_time`）。

### 锁屏背景

背景图需要预先生成（2560×1440 约 10 秒），所以：

- 每次换壁纸后（开机时和每 5 分钟），`bin/autostart.sh` 会在后台执行 `bin/blurlock.sh update` 重新生成。壁纸没变时会跳过。
- 第一次锁屏时如果还没有背景图，会先生成再锁屏，稍等几秒。

### 修改

| 想改什么 | 改哪里 |
|---|---|
| 自动锁屏的等待时间 | `bin/dpms.sh` 里的 `IDLE_SEC`（单位是秒）；`config/betterlockscreenrc` 的 `lock_timeout` 要改成一样的值 |
| 调暗、模糊程度 | `config/betterlockscreenrc` 里的 `dim_level`、`blur_level` |
| 颜色、字体、提示文字 | `config/betterlockscreenrc` |
| 时间、日期、竖条的位置和大小 | `bin/blurlock.sh` 里 `--` 之后的参数（竖条是 `--bar-*`） |

修改 `config/betterlockscreenrc` 后，执行 `bin/blurlock.sh update -f` 重新生成背景才会生效；修改 `bin/blurlock.sh` 立即生效；修改 `dpms.sh` 要重新登录才会生效。

> 锁屏依赖 `betterlockscreen` 和 `i3lock-color`，执行 `./setup.sh deps` 会安装。可以执行 `pacman -Q betterlockscreen i3lock-color` 确认是否已安装。
>
> 显示圆点需要本仓库 `i3lock-color/` 里改过的 i3lock-color，执行 `./setup.sh i3lock` 编译安装为 `/usr/local/bin/i3lock-color`。没装时锁屏照常可用，只是不显示圆点。

## 2. 截图（flameshot）

| 按键 | 功能 |
|---|---|
| `Super + Shift + A` | 框选区域截图 |

截图时的操作：

| 操作 | 功能 |
|---|---|
| 鼠标拖动 | 选择截图区域；拖动选区边缘可以调整大小 |
| 工具栏 | 在选区上加箭头、方框、文字、马赛克等标注 |
| `Ctrl + C` | 复制到剪贴板，并结束截图 |
| `Ctrl + S` | 直接保存到 `~/Pictures`（不弹对话框），并结束截图 |
| `Esc` | 取消 |

保存位置由 flameshot 自己的配置 `~/.config/flameshot/flameshot.ini` 决定（`savePath`，`savePathFixed=true` 表示不弹对话框）。

截图后直接在聊天软件等地方 `Ctrl + V` 就能粘贴。
