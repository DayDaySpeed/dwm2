**最常用的几个按键：**

| 按键 | 功能 |
|---|---|
| `Super + Enter` | 打开终端 |
| `Super + D` | 运行命令 |
| `Super + Q` | 关闭窗口 |
| `Super + 1 / 2 / 3` | 切换 tag |
| `Super + Shift + A` | 截图 |
| `Super + N` | 锁屏 |
| `Super + Ctrl + F12` | 退出 dwm |
