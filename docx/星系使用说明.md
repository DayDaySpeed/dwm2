# Super+Z 3D 工作空间星系

按 **Super+Z**，当前桌面会“碎开”或“起飞”，所有 tag 和窗口变成一个三维星系群：

- 每个 **tag** 是一个**星系核心**（粒子恒星）；
- 每个**窗口**是绕核心公转的一颗**窗口星**（带实时截图的卡片）；
- 所有 tag 一起组成**星系群**，绕着中央的**双星**沿三条开普勒椭圆轨道公转。

在星系里可以浏览、搜索、切换窗口，也可以把它当屏保。

---

## 一、基本概念

| 星系里的东西 | 对应的桌面元素 |
|---|---|
| 星系核心（一团旋转的粒子恒星，带吸积盘） | 一个 tag，颜色是这个 tag 的专属色 |
| 窗口星（窗口截图卡片） | tag 里的一个窗口，沿核心周围的轨道环运行 |
| 中央双星（一冷一暖两团粒子恒星） | 星系群的共同焦点，三条群轨道都绕着它 |
| 群轨道（内 / 中 / 外三条椭圆） | 有窗口的 tag 在内、中轨，空 tag 在外轨 |
| 核心身后的大拖尾 | 星系核心在群轨道上走过留下的光尘 |
| 窗口星身后的小拖尾 | 窗口星绕核心公转留下的细光尘 |

整个动画期间**不会移动、隐藏、映射或聚焦任何真实窗口**，只在结束时恢复，或者按你的选择切换 tag 和焦点。

---

## 二、操作

### 进入和退出

| 操作 | 效果 |
|---|---|
| **Super+Z**（桌面上） | 进入星系，播放开场（约 7.7 秒），然后停在星系轨道态（不限时） |
| **Super+Z**（星系里） | 回程：窗口星飞回原位、变回截图，露出真实桌面 |
| **Esc**（星系里） | 收尾：星系群卷成旋涡被吸进中心，冲击波揭开壁纸，停在纯壁纸画面 |
| 停在壁纸时按任意键 / 点击 / Super+Z | 恢复桌面 |
| 开场中按 Esc / Super+Z | 直接进入收尾 / 回程 |

### 键盘（驻留时）

| 按键 | 作用 |
|---|---|
| 直接打字 | 按窗口标题过滤（不区分大小写），屏幕下方显示过滤框和匹配数 |
| 方向键 | 在窗口星之间移动选中 |
| Tab / Shift+Tab | 在匹配项之间轮换 |
| Enter | 进入选中的窗口（落位动画后切到那个窗口） |
| Backspace | 删除过滤词的最后一个字符 |
| Esc | 有过滤词或选中时先清空；没有时开始收尾 |
| F12 | 帧率面板（帧率、渲染时间、GPU 合成、截图刷新、CPU 扫描） |

### 鼠标（驻留时）

鼠标默认是**休眠**的，第一下**左键点击只用来唤醒**，不会选中任何东西。唤醒后：

| 操作 | 作用 |
|---|---|
| 悬停在卡片上 | 卡片朝指针方向轻微倾斜、浮起、边缘光变亮 |
| 悬停在核心上 | 核心下方显示 tag 图标、窗口数和前几个窗口的标题 |
| 左键点卡片 | 卡片上泛起一圈涟漪，然后落位到该窗口 |
| 左键点核心 | 核心亮起，然后切到该 tag |
| 按住左键拖动卡片到另一个核心上松手 | 把窗口移到那个 tag，卡片沿弧线飞进新星系的轨道 |
| 中键点卡片 | 关闭这个窗口，它化作一颗流星飞走 |
| 右键拖动 | 旋转视角 |
| 滚轮 | 缩放（默认最近，向下滚拉远） |
| 一段时间不操作 | 鼠标重新休眠，导演镜头恢复自动运镜 |

开场中鼠标同样默认休眠：先左键唤醒，再点击，开场就会在约 0.6 秒内快进到驻留态。

## 三、完整流程

### 1. 开场（约 7.7 秒）

每次进入随机轮换三套开场（不连续重复；环境变量 `GALAXY_VARIANT=A|B|C` 可以固定一套）：

- **A 碎裂**：桌面碎成 20×12 块玻璃片，由近及远依次绕画面中心旋涡状收缩、自转、变小。碎片转动时边缘迎光发亮，末端化成拖尾的光点；碎裂那一刻有一次很短的漏光。
- **B 星门**：一座正对镜头的光环从远处迎面而来，环上 12 个光点在跑，外圈 9 个 V 形标记反向慢转；镜头从环中穿过的一刻有一道淡淡的光。
- **C 大爆炸**：焦点窗口的中心先向内收紧，然后爆发，两圈冲击波，粒子向四周喷射；各个核心从爆心飞出后再点火。

三套之后的节拍相同：
1. **起飞**：窗口截图脱离桌面，变成卡片飞向太空；壁纸溶解成深空。
2. **超空间跃迁**：尘埃沿画面中心向外拉成光线。
3. **轨道描绘**：三条群轨道依次显现；各核心在自己的轨道平面里点火，发出冲击环。
4. **螺旋旋转**：星系群高速自转一圈，到转速峰值时盘面上扩散出一圈大冲击环。
5. **俯冲**：镜头冲进星系群，铺满全屏。
6. **点名**：有窗口的星系依次亮起。
7. **星轨拉出、卡片翻面**：卡片翻转到朝向镜头。
8. **弧线回缩**：镜头沿弧线退回全景，回缩落定的一刻中心发出一圈大涟漪，进入驻留。

开场全程，核心和窗口星身后都拖着粒子尾迹，尾迹紧跟星体，并随星系群一起转动。

### 2. 驻留（星系轨道态）

- **公转**：核心沿三条开普勒椭圆群轨道运行，近点快、远点慢；窗口星绕核心转。
- **导演镜头**：自动轮换机位：全景、巡游（飞近某个星系）、俯视等，每个机位约 9 秒，切换时平滑飞越。镜头还有极慢的“呼吸”漂移。
- **交互让位**：唤醒鼠标、拖动或悬停时，导演镜头平滑停住，公转放慢到 30%，方便点中。
- **卡片实时刷新**：每帧最多刷新一张截图，同一张至少隔 2 秒（安静模式 6 秒）。
- **帧率**：驻留时跟随显示器刷新率（60~360Hz）；无操作 90 秒后降到 30fps。

### 3. 退出

- **Esc 收尾**（约 2.85 秒）：
  1. 星系群沿轨道再划过一段弧线，核心的大拖尾逐渐放长；
  2. 所有粒子（尾迹、吸积盘、粒子恒星、星尘）各自带着先后，绕星系群的轴旋进中心，形成旋涡，越近越亮越白；同时背景被引力透镜拽向中心；
  3. 收拢成一个亮核的同时，冲击波爆出；
  4. 冲击波以圆形揭开壁纸，边缘带一点色差，粒子随冲击波从中心炸开、淡出；
  5. 余晖散去后，停在纯壁纸（动态壁纸会继续播放）。
- **Super+Z 回程**（1.6 秒）：窗口星沿 3D 弧线飞回原位、变回截图，其他星体退向深处、镜头回正。快结束时，回到原位的卡片上扫过一道细光；最后一帧与真实桌面逐像素一致。
- **落位**（点卡片 / Enter，0.95 秒）：选中的卡片领先沿弧线飞到真实窗口的位置，同屏的其他窗口随后归位；其余卡片和核心加速退向深处，身后拖出快速光尘，像被吸进去。
- **点核心**：核心亮起后切到那个 tag。

## 四、视觉元素

### 恒星与星系核心

- **粒子恒星**：每个核心是一团约 2600 颗 GPU 粒子，球形分布、中心密外围疏、略扁，绕自转轴内快外慢地转，并缓慢涌动；中心暖白，外圈是 tag 色；外面只有一层很淡的光晕。没有刺眼的光斑或星芒。
- **吸积盘**：每个核心一圈 4000~9000 颗粒子，按开普勒规律内快外慢，内圈白热、外圈 tag 色，带两条淡淡的旋臂。
- **大拖尾**：核心在群轨道上走过的地方留下光尘。粒子生成后固定在原地，慢慢散开变暗；越靠近核心越亮越紧，越往后越宽、颜色从白热过渡到 tag 色。最长约星系群半径。
- **中央双星**：一冷一暖两团粒子恒星，绕共同质心互转，是三条群轨道的共同焦点。

### 窗口星（卡片）

- 窗口截图卡片由 GPU 绘制，透视准确，缩小后文字平滑不闪；
- 驻留时有一圈 tag 色的边缘光，转动时一道高光从卡面扫过，卡面还会映出所属核心的颜色；
- **小拖尾**：卡片绕核心公转，身后拖一条细短的光尘；
- 快速移动（开场、回程、落位）时有运动模糊；
- **请求关注**的窗口：卡片背后一圈脉动的红光（“红星”）；
- **CPU 色温**：卡片的颜色跟随它进程的 CPU 占用：闲时是 tag 色，约 30% 时暖白，80% 以上时橙红；占用按进程树汇总，终端里跑的程序算在终端窗口上。

### 背景（远景，不抢焦点）

- 稀疏的星点（三层视差）和稀疏闪烁的小星；
- 两个很小的远方星系（旋涡或椭圆），极慢地自转；
- 三颗偶尔闪一下、露出很小十字星芒的亮星；
- 被照亮的星尘：星系群周围约 1.6 万颗，本身不发光，只有靠近核心或中央双星时才被照亮、染上它的颜色，并跟着星系群一起转；
- 画面中央压暗，四边渐隐，焦点留给星系和卡片。

### 光效

- 光层在线性空间里合成，亮处保留颜色，不烧成白饼；泛光逐级加权，衰减自然；
- 中央光源有淡淡的体积光束；
- 大闪光之后有短暂的曝光适应（画面略压暗再恢复）；
- 只有很亮的光源（大爆炸、超新星、收尾闪光）才出现镜头光晕；
- 天象全部是三维粒子：超新星、脉冲星、彗星、光桥、星座连线、涟漪、冲击环都由 GPU 粒子发射器生成，在世界空间里有视差、会被卡片遮挡；其余光斑是缓慢旋转、闪烁的星尘。

## 五、天象与事件

### 驻留时周期发生（强度随驻留程度，安静模式间隔约 ×2.5）

| 天象 | 大约多久一次 | 表现 |
|---|---|---|
| 星系翻转 | 每 5 秒轮到一个有窗口的星系 | 用 3.2 秒绕自己的轨道平面翻转一整圈，吸积盘外缘随之甩出一圈薄薄的光尘 |
| 星座连线 | 每 4 秒 | 细粒子流从核心开始依次长出，按轨道角把一个星系的卡片连起来，停留后散成星尘 |
| 涟漪 | 每 6 秒 | 中央双星发出一圈粒子波在盘面扩散，经过处的吸积盘、拖尾、星尘被托起、点亮，扫过的核心短暂亮起 |
| 核心光桥 | 每 7 秒 | 粒子沿弯曲的路径从一个核心流向另一个不同轨道上最近的核心（像双星间的物质转移），到达时溅起一小团粒子 |
| 超新星 | 每 20 秒 | 一个看得见的核心先收缩变暗 0.3 秒，然后约 8000 颗粒子球壳爆发（白 → 蓝紫 → 橙，纤维状，减速扩张约 3 秒），留下慢慢散开的残骸星云，同时照亮附近的星尘 |
| 彗星 | 每 15 秒 | 粒子彗头从星系群外侧穿过盘面；蓝色离子尾笔直背向中央光源、粒子快速外流，白色尘埃尾宽而弯、流得慢，两条尾巴都越往后越散越淡 |
| 零星流星 | 每 3~8 秒 | 远处一颗细淡的流星从画面外圈划过，被卡片遮挡，身后留下慢慢消散的余迹，结束时迸出几点碎火 |
| 流星雨 | 每 31 秒 | 1.5 秒内从画面一侧上方斜着射出十来颗，同样带余迹 |
| 远处彗星 | 每 45 秒 | 用 16 秒从画面上方或下方远处慢慢飘过，头部小光点 + 逐渐张开、闪烁的光尘彗尾 |
| 脉冲星 | 持续 | 一个空 tag 的核心沿磁轴喷出两股相反的粒子流（青 → 蓝紫），绕倾斜的轴每 14 秒扫一圈，扫向镜头时闪亮 |

### 由运动自然产生

| 现象 | 表现 |
|---|---|
| 近点甩掠 | 核心经过椭圆轨道近点时更亮更大、速度更快 |
| 交会 | 不同轨道上的两个核心靠近时同时闪光，并沿连线互相吸引一点 |
| 掩食 | 一个核心从另一个前面经过时，后方的核心被压暗 |

### 由桌面事件触发

| 事件 | 表现 |
|---|---|
| 新开窗口 | 在它所在 tag 的星系里诞生一颗新星：一点光亮起、光晕扩开、卡片展开，放在轨道上最大的空隙里 |
| 关闭窗口（含中键点卡片） | 卡片 0.4 秒内缩成光点，迸出一团火花，沿轨道切线拖着长尾飞走 |
| 收到通知（dunst） | 化作一颗带标题的彗星划过画面，同时最多 2 颗，排队显示；屏保模式下只显示应用名 |
| 整点 | 中央双星的粒子团变亮、胀大，盘面上扩散两圈慢速大光波（扫到的核心亮起），双星旁显示时间 |
| 窗口请求关注 | 卡片背后出现脉动的红光 |

天象发生时，随机特效会让位约 3 秒。

## 六、模式与设置

### 模式

- **屏保模式**：无操作 10 分钟后，`bin/galaxysaver.py` 以屏保模式进入星系（任何输入都回到桌面）；20 分钟后由 xss-lock 锁屏（见 `bin/dpms.sh`）。屏幕关闭（DPMS）时星系暂停渲染。
- **安静模式**：省电模式（Super+P，拔电时自动打开）下，特效间隔 ×2.5，粒子数量减半，驻留帧率 30fps。
- **减弱动效**：对强光、闪烁敏感时使用。执行 `touch ~/.cache/galaxy-gentle`，或设置环境变量 `GALAXY_GENTLE=1`，下次 Super+Z 生效；删掉文件即恢复。效果：
  - 闪白、爆闪、收尾闪光只留四分之一；
  - 不做透镜扭曲、镜头光晕、曝光骤降和色差；
  - 星点不闪烁，粒子流变慢，中央双星不爆闪，收尾的粒子爆发范围减半。
- **质量自动降级**：渲染跟不上时自动减少泛光级数和粒子数量，关掉色差和颗粒。

### 可调参数（`config/dwm.h`，改完按 Super+Shift+R 重新编译生效）

| 参数 | 默认 | 说明 |
|---|---|---|
| `GALAXY_INTRO` | 1.35 | 开场时间拉伸，越大越慢（1.35 约 7.7 秒） |
| `GALAXY_FXGAP` | 1.0 | 驻留特效间隔的倍数，2 表示特效少一半 |
| `GALAXY_DIAG` | 30 | 驻留时镜头翻滚角度（度），轨道盘面沿屏幕对角线铺开；0 为水平 |
| `GALAXY_TOURDIST` | .5 | 巡游镜头离星系的距离，越小越近 |
| `GALAXY_SHOT` | 9.0 | 每个机位停留的秒数 |
| `GALAXY_QUIETFPS` | 30 | 安静模式的驻留帧率 |

### 测试用环境变量

| 变量 | 作用 |
|---|---|
| `GALAXY_VARIANT=A\|B\|C` | 固定开场：碎裂 / 星门 / 大爆炸 |
| `GALAXY_FAKETIME=帧率` | 确定性时钟，每帧前进固定步长 |
| `GALAXY_DUMP=秒,秒…` + `GALAXY_DUMPDIR` | 在指定时刻导出底层画面（PPM） |
| `GALAXY_FAKEHOUR=秒` | 驻留这么多秒后假装到了整点 |
| `GALAXY_TRACE=1` | 每帧把镜头参数和核心位置写进日志 |
| `GALAXY_FXGAP=倍数`（或文件 `~/.cache/galaxy-fxgap`） | 覆盖驻留特效间隔倍数，.25 表示天象快 4 倍（测试用） |

## 七、技术说明

- **代码**：`dwm/galaxy.c`（入口和数据结构），以及以下文件：
  - `galaxy-gl.c`：OpenGL 渲染、着色器、GPU 粒子；
  - `galaxy-scene.c`：场景、镜头、轨道；
  - `galaxy-render.c`：每帧绘制；
  - `galaxy-space.c`：深空和远景；
  - `galaxy-build.c`：截图、建场景、日志；
  - `galaxy-control.c`：输入、流程、天象调度；
  - `galaxy-heat.c`：CPU 色温。
- **三层合成**：
  - 底层是 XRender，画壁纸、深空星点、卡片的后备路径；
  - 光层是 OpenGL，画光点、粒子、泛光，用 HDR 加法混合；
  - 卡片层是 GPU 截图纹理；
  - 前景层是 XRender，画文字、标签、状态栏；
  - 每帧由 GPU 合成到全屏遮罩窗口。
- **GPU 粒子**：粒子恒星、吸积盘、拖尾、星尘都不保存状态，每颗粒子的位置由编号、种子和时间在着色器里算出，一次绘制几千到上万颗。拖尾按星体过去的位置回溯生成，粒子在世界中固定，所以有真实的视差和遮挡。
- **性能**（参考 2560×1440、240Hz、NVIDIA）：驻留约 220~230fps，每帧渲染约 3~3.5ms；开场和收尾约 118fps。dwm 启动时会预先生成深空背景，第一次开场不卡顿。
- **首末帧一致**：开场第一帧和回程 / 落位的最后一帧都与真实桌面逐像素一致，进出星系看不出切换。
- **日志**：`~/.cache/dwm-galaxy.log`，测试显示器是 `~/.cache/dwm-galaxy:N.log`。里面记录每段的帧率、渲染耗时、天象、截图刷新、光层亮度等。
- **合成器配合**：picom（仓库内 v13）。星系和总览的遮罩不加阴影、圆角、模糊和动画；dwm 交接时设置 `_DWM_NOANIM`，这段时间 picom 不做窗口动画。
- **测试脚本**：`dwm/tests/galaxy/`。
  - `start.sh` 启动独立的测试会话（Xvfb + picom + 测试副本 dwm）；
  - `interrupt.sh` 测各状态下的中断和按键（16 项）；
  - `mouse.sh` 测鼠标；
  - `events.sh` 测天象；
  - `loop.sh 40` 连续进出 40 次，检查内存和 X 资源。
