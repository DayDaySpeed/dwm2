# 终端使用说明（st + tabbed）

终端由两个程序组成：

- **st**：终端本体（yaocccc/st），配置在 `config/st.h`。
- **tabbed**：在 st 外面套一层，负责多标签（yaocccc/tabbed），配置在 `config/tabbed.h`。

在 dwm 里按 `Super + Enter` 打开的就是「tabbed 管理的 st」。

---

## 1. 打开终端

| 按键 | 打开方式 | 实际命令 |
|---|---|---|
| `Super + Enter` | 普通终端 | `tabbed -n st -C tabbed -c -r 2 st -w ''` |
| `Super + -` | 浮动、全局终端 | `tabbed ... -C FG ...` |
| `Super + S` | scratchpad 终端（再按一次隐藏） | `tabbed -n scratchpad ...` |

tabbed 的参数：`-c` 表示最后一个标签关闭时整个窗口也关闭，`-C` 指定窗口 class（决定 dwm 按哪条规则处理它）。

---

## 2. 标签操作（tabbed）

| 按键 | 功能 |
|---|---|
| `Ctrl + Enter` | 新建标签 |
| `Ctrl + Tab` | 下一个标签 |
| `Ctrl + Shift + H` / `Ctrl + Shift + L` | 上一个 / 下一个标签 |
| `Ctrl + Shift + K` / `Ctrl + Shift + J` | 当前标签左移 / 右移 |
| `Ctrl + 1` … `Ctrl + 9`、`Ctrl + 0` | 跳到第 1 … 10 个标签 |
| `Ctrl + Q` | 关闭当前标签 |

只有一个标签时，标签栏自动隐藏；有两个及以上标签时才显示。

> 这些快捷键会被 tabbed 截获，终端里运行的程序收不到。作者原配置还占用了 `PageUp` / `PageDown` / `Home` / `End`（导致 vim、less 里无法翻页），已从 `config/tabbed.h` 中移除。

---

## 3. 复制与粘贴（st）

| 操作 | 功能 |
|---|---|
| 鼠标选中文字 | 自动复制到「选区剪贴板」（PRIMARY） |
| 鼠标中键 / 右键 | 粘贴选区剪贴板的内容 |
| `Shift + Insert` / `Ctrl + Shift + Y` | 粘贴选区剪贴板的内容 |
| `Ctrl + Shift + C` | 复制到系统剪贴板（CLIPBOARD） |
| `Ctrl + Shift + V` | 粘贴系统剪贴板的内容 |

双击选中一个词，三击选中一整行。

> 从浏览器等程序用 `Ctrl + C` 复制的内容在系统剪贴板里，要用 `Ctrl + Shift + V` 粘贴；用鼠标选中的内容用中键粘贴。

---

## 4. 滚动与缩放（st）

| 操作 | 功能 |
|---|---|
| 鼠标滚轮 | 向上 / 向下滚动历史输出 |
| `Ctrl + 鼠标滚轮` | 按整页滚动 |
| `Ctrl + Shift + PageUp` | 放大字体 |
| `Ctrl + Shift + PageDown` | 缩小字体 |
| `Ctrl + Shift + Home` | 字体恢复默认大小 |

st 没有配置用键盘滚动历史的快捷键，只能用鼠标滚轮。

---

## 5. 命令行参数（st）

作者的 st 加了几个补丁，所以有些额外的参数：

| 参数 | 作用 | 例子 |
|---|---|---|
| `-c class` | 指定窗口 class，用来配合 dwm 的窗口规则 | `st -c float` 打开浮动终端 |
| `-t title` | 指定窗口标题 | `st -t music` |
| `-g 列x行+X+Y` | 指定大小和位置 | `st -g 80x20+100+100` |
| `-e 命令` | 启动后直接运行命令 | `st -e btop` |
| `-A 透明度` | 指定背景透明度（0~1） | `st -A 0.7` |
| `-C '颜色@编号'` | 启动时临时替换某个颜色 | `st -C '#222D31@4'` |

---

## 6. 当前配置（`config/st.h`）

| 项目 | 值 |
|---|---|
| 字体 | JetBrainsMono Nerd Font Mono，20 像素 |
| 背景透明度 | 0.95 |
| 背景色 / 前景色 | `#222D31` / `#B5B5B5` |
| 配色 | Dracula 风格（红 `#ff5555`、绿 `#50fa7b`、紫 `#bd93f9` 等） |
| 默认大小 | 100 列 × 30 行 |
| 光标 | 方块，不闪烁 |
| TERM | `st-256color` |

**已启用的补丁：** 透明度、任意窗口尺寸、减少刷新闪烁、制表符无缝拼接（boxdraw）、启动时自定义颜色、输入时隐藏鼠标、连字、历史滚动。

### 修改方法

1. 编辑 `config/st.h`，比如改字体大小：把 `pixelsize=20` 改成其他值。
2. 在项目根目录执行 `./setup.sh st`。
3. 新打开的终端生效，已经打开的终端不受影响。

tabbed 同理：编辑 `config/tabbed.h`，然后执行 `./setup.sh tabbed`。

## 7. ranger 文件管理器

在终端里执行 `ranger`。配置文件在 `config/ranger/`（`~/.config/ranger` 软链接到这里）。

**图片预览：** 光标移到图片上，右侧的预览栏会直接显示图片，不用按 `Enter` 打开。视频会显示缩略图，PDF 会显示第一页。
这依赖 `ueberzugpp`（负责把图片叠加到 st 窗口上）和 `ffmpegthumbnailer`（生成视频缩略图），安装命令：`sudo pacman -S ueberzugpp ffmpegthumbnailer`。

| 按键 | 功能 |
|---|---|
| `h` / `j` / `k` / `l` | 上一级目录 / 下移 / 上移 / 进入目录或打开文件 |
| `gg` / `G` | 跳到第一个 / 最后一个 |
| `Space` | 选中（可以多选）；删除多个文件时会再问一次 `y/N` |
| `yy` / `dd` / `pp` | 复制 / 剪切 / 粘贴 |
| `cw` | 重命名 |
| `dT` + `Enter` | 移到回收站（可用 `trash-list` 查看、`trash-restore` 恢复） |
| `dD` + `Enter` | 彻底删除 |
| `zh` | 显示 / 隐藏隐藏文件 |
| `zi` | 开启 / 关闭图片预览 |
| `/` | 搜索 |
| `q` | 退出 |
