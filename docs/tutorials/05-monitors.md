# 教程 5：多显示器

**你会做到：** 接上外接显示器，选好摆放位置、分辨率、刷新率、方向和缩放；理解两块屏时焦点和键盘的规则；知道外接屏文字为什么可能发糊、怎么取舍。
**需要多久：** 10 分钟。
**前提：** 一台笔记本加一块外接屏（台式机多屏同理，只是没有"笔记本屏"）。显示器相关的操作都由 `bin/monitor.sh` 处理。

---

## 1. 接上外接屏

插上之后最多 10 秒，桌面会检测到：

- **以前用过的接法**（同样的几块屏）：自动套用上次的布局，每块屏的分辨率、刷新率、方向、缩放也按上次的。
- **第一次的接法**：外接屏先扩展到笔记本屏右侧，弹通知提示到菜单里调整。

拔掉外接屏时，如果笔记本屏是关着的（比如之前选了"仅外接屏"），会自动点亮笔记本屏，不会黑屏。

## 2. 选布局

`Super + P` → `󰍹 monitor layout`。主菜单上面是布局，下面每块屏一行，写着它现在的分辨率、刷新率、方向、位置和缩放：

| 选项 | 效果 |
|---|---|
| 外接屏在右侧 / 左侧 / 上方 / 下方 | 扩展桌面，按实际摆放位置选，鼠标才能自然地移过去 |
| 复制 | 所有屏显示相同内容（投影、演示） |
| 仅外接屏 | 关掉笔记本屏（合盖接显示器用） |
| 仅笔记本 | 关掉外接屏 |
| 某块屏 | 进这块屏的菜单，见下表 |

每块屏的菜单（当前的选项打 `󰄬`，选完立即生效，留在这个菜单里可以接着调）：

| 选项 | 效果 |
|---|---|
| 分辨率 | 这块屏支持的分辨率，默认用首选的 |
| 刷新率 | 当前分辨率支持的刷新率，默认用最高的；省电模式开着时统一 60Hz，关掉后回到这里选的 |
| 旋转 | 不旋转 / 向左转 90°（逆时针）/ 向右转 90°（顺时针）/ 转 180°，竖着放的屏选 90° |
| 镜像翻转 | 不翻转 / 水平 / 垂直 / 水平+垂直，投影仪背投、提词器之类用 |
| 缩放 | 这块屏的缩放，见第 4 节 |
| 位置（外接屏） | 在笔记本屏右侧 / 左侧 / 上方 / 下方、复制、关闭 |
| 开关（笔记本屏） | 开启 / 关闭，只在接了外接屏时出现 |

没接外接屏时，菜单直接就是笔记本屏自己的这一层（分辨率、刷新率、旋转等）。子菜单里按 `Esc` 或选 `↩ 返回` 回到上一层。

**多块外接屏**：每块外接屏单独设位置，同一方向的几块按接口名依次往外排（比如两块都在右侧，就是 笔记本 | HDMI-0 | DP-1）。选"仅外接屏"时笔记本屏关掉，外接屏之间的相对位置不变。台式机没有笔记本屏，以其中一块为基准，其它屏围绕它摆放；某块屏的"位置"里选"设为基准"可以换基准屏，摆放保持不变。

设置都**按显示器记住**（按 EDID 识别，换了接口也认得），保存在 `~/.config/dwm-monitor/`：每块屏的分辨率、刷新率、方向、缩放各一份，每种接法（连着哪几块屏）的布局一份。

## 3. 两块屏怎么用

两块屏是**同一个 dwm**，但每块屏各有自己的一套 tag、布局和状态栏：笔记本屏可以看 tag 1，外接屏同时看 tag 3。

**键盘控制哪块屏：** 任何时刻只有一块屏是"选中"的，键盘输入和 dwm 快捷键（切 tag、换布局、`Super + Q`…）都只作用于它。看哪个窗口的边框是高亮的就知道是哪块。

| 怎么切换选中的屏 | 说明 |
|---|---|
| 鼠标移过去 | 移到另一块屏的窗口上或空桌面上，就切过去 |
| `Super + B` | 切到另一块屏，鼠标也跟着移过去 |
| `Super + Shift + B` | 把当前窗口送到另一块屏（焦点留在原来的屏） |

键盘操作时鼠标指针会自动隐藏。隐藏期间以键盘为准，鼠标一动就重新以指针所在的位置为准。

## 4. 缩放和清晰度

### 为什么要设缩放

笔记本屏通常像素密度高（如 14～16 寸 2560×1440），外接屏低（如 24 寸 1920×1080）。同样的字号，在笔记本上太小，在外接屏上又偏大，所以两块屏要用不同的缩放。

- **外接屏**：默认 100%
- **笔记本屏**：默认按分辨率猜（宽 ≥ 2560 时 135%，否则 100%）

每块屏都可以在 100～200% 之间另选。

### X11 的限制

X11 下整个桌面只能有**一个**缩放比例，程序启动时读一次就定死了。所以这里的做法是：

- 全局缩放固定用**笔记本屏**的缩放（只用外接屏时用基准外接屏的）。
- 其它屏要显示成自己的缩放时，先按"全局缩放 ÷ 这块屏的缩放"倍放大的尺寸画出来，再缩小显示（`xrandr --scale`）。

例如笔记本 135%、外接屏 100%：外接屏先按 2592×1458 画，再缩到 1920×1080。大小对了，但缩小 1.35 倍不是整数倍，**文字边缘会发软**。

### 怎么选

| 你在意 | 外接屏缩放选 | 效果 |
|---|---|---|
| 外接屏文字最清楚 | 和笔记本屏一样（如 135%） | 不缩放，原生像素显示；但外接屏上界面偏大、一屏放的内容变少 |
| 两块屏大小都合适 | 100%（默认） | 大小合适，外接屏文字略软 |
| 折中 | 125% | 缩放倍数小，几乎看不出软 |

改外接屏缩放立即生效，不用重开程序。改**笔记本屏**缩放会改全局缩放：dwm 会原地重启（窗口保留），已经打开的程序要重开才会变。

两块屏都清晰又各用各的缩放，只有 Wayland 能做到（每块屏单独缩放，程序直接按目标倍数渲染）。

## 5. 其他

- **锁屏**：两块屏都会锁，时间和密码提示显示在各自屏幕的中间。
- **壁纸**：两块屏显示同一张壁纸，各自完整铺满，不会一张画面横跨两块屏；视频 / 场景每屏各开一个，切换时两块屏同时播转场。切换布局后会按新的屏幕重新挑。复制模式下两块屏显示同一张。
- **刷新率**：每块屏默认用最高刷新率（可在菜单里另选）；省电模式下降到 60Hz。
- **旋转**：转成竖屏后，dwm、状态栏、壁纸、锁屏都按竖屏的大小重新排。
