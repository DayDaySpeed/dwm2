# 教程 2：快速上手

**你会做到：** 理解 dwm 的几个基本概念，跟着做一遍最常用的操作。
**需要多久：** 15 分钟。
**前提：** 已经按 [教程 1](01-install.md) 进入桌面。

下文的 `Super` 指键盘上的 Windows 键。

---

## 1. 先认识屏幕

```
┌────────────────────────────────────────────────────────────────────┐
│ 󰎧 󰎪 …   󰙀   当前窗口标题            󰒇 09%  󰍛 48%  10/13  󰕾 55%  ← 状态栏
├────────────────────────────────────────────────────────────────────┤
│ ┌───────────────────────┐ ┌──────────────────┐                     │
│ │                       │ │   次要区域        │                     │
│ │      主区域            │ ├──────────────────┤                     │
│ │   (新窗口的位置)        │ │   次要区域        │                     │
│ └───────────────────────┘ └──────────────────┘                     │
└────────────────────────────────────────────────────────────────────┘
```

- **tag**：状态栏最左边的一排图标，相当于"虚拟桌面"。前三个是通用的（`Super + 1/2/3`），后面几个绑定了应用：`Super + C` Chrome、`Super + W` Edge、`Super + V` VSCode、`Super + M` 音乐、`Super + 0` Steam、`Super + 9` OBS。按这些键时，如果那个 tag 上还没有窗口，就会顺便把应用打开；窗口被隐藏了会恢复；已经在那个 tag 上再按，就在它的几个窗口之间轮流切换。
- **平铺**：窗口不重叠，自动排满屏幕。左边是**主区域**（一个大窗口），右边是**次要区域**（其余窗口竖着排）。
- **浮动**：像普通桌面那样可以自由拖动、重叠的窗口。对话框、截图工具等会自动浮动。
- **布局图标**：tag 后面的图标，`󰙀` 是主次布局，`󰕰` 是网格布局。
- **状态栏右侧**：CPU、内存、日期、音量、电量等。可以点击：左键看详情，右键打开相关工具。

## 2. 跟着做一遍

按顺序操作一次，大约 10 分钟。

1. **开终端**：`Super + Enter`，再按两次，开出三个终端，观察主区域和次要区域怎么排。
2. **切换焦点**：`Super + ↑ / ↓` 在本 tag 的窗口间切换；`Super + H/J/K/L` 按方向切换；`Super + Tab` 回到上一个用过的窗口。
3. **调整布局**：
   - `Super + Shift + Enter`：把当前窗口放进主区域
   - `Super + , / .`：缩小 / 放大主区域
   - `Super + Space`：在主次布局和网格布局之间切换
4. **开应用**：`Super + D` 打开启动器，输入几个字母（如 `pcman`）回车。
5. **切换 tag**：`Super + 2` 到第二个 tag，再开个终端；`Super + 1` 回来。`` Super + ` `` 在最近两个 tag 之间来回切。
6. **把窗口搬到别的 tag**：选中一个终端，按 `Super + Shift + 3`，它就去了 tag 3。
7. **浮动和全屏**：`Super + T` 让当前窗口浮动（再按回到平铺），按住 `Super` 用左键拖动、右键调大小；`Super + F` 全屏。
8. **窗口总览**：`Super + A`，所有窗口铺成网格，可以打字过滤，点一下就跳过去。
9. **星系**：`Super + Z`，所有 tag 和窗口变成一个 3D 星系，点卡片或按 Enter 跳到那个窗口，`Super + Z` 回桌面。详见 [星系手册](../manual/galaxy.md)。
10. **关窗口**：`Super + Q`。
11. **截图**：`Super + Shift + A`，框选后可以标注、复制、保存。
12. **锁屏**：`Super + Ctrl + L`，输密码解锁。
13. **电源菜单**：`Super + Shift + Esc`，有睡眠、注销、重启、关机。

## 3. 记不住按键时

按 `Super + /`：列出所有快捷键，可以搜索（只查看，不执行）。这份列表直接从 `config/dwm.h` 生成，改了快捷键也会跟着变。

最常用的几个：

| 按键 | 功能 |
|---|---|
| `Super + Enter` | 终端 |
| `Super + D` | 启动应用 |
| `Super + Q` | 关闭窗口 |
| `Super + 1/2/3` | 切换 tag |
| `Super + A` | 窗口总览 |
| `Super + Z` | 星系 / 回到桌面 |
| `Super + P` | 设置菜单：壁纸模式、省电、勿扰、护眼、显示器… |
| `Super + X` | 剪贴板历史 |
| `Super + S` | 下拉终端（随叫随到的 scratchpad） |
| `Super + /` | 快捷键速查 |

## 4. 设置菜单 Super + P

日常开关都在这里：

- 动态 / 静态壁纸切换
- 省电模式：静态壁纸 + 60Hz + CPU 节能；拔电时自动打开
- 勿扰：暂停弹出通知
- 暂停自动锁屏：看视频、演示时用
- 护眼：屏幕变暖色
- 显示器布局：接外接屏时用，见 [教程 5](05-monitors.md)
- 开关 picom、Sunshine、VNC

完整说明见 [rofi 手册](../manual/rofi.md)。
